# Walmart expert curriculum

Version: 2026-07-18. This curriculum is incremental: each run selects only modules with stale evidence, failed evaluations, incomplete country coverage, or newly observed authorized-store evidence.

## Progress states

- `foundation_verified`: official public evidence and regression coverage exist; this does not prove a live store connection.
- `learning_only`: evidence is incomplete, stale, single-country, or not validated on an authorized task.
- `blocked_owner_input`: progress requires a real store, account scope, document, consent, or approval from the owner.
- `operationally_validated`: requires a scoped authorized store task, recorded inputs/results, and no fabricated completion state.

## Selection rule per run

Choose at most three modules in this order: newly failed evaluations, official changes since the previous capture, evidence expiring within 14 days, country gaps, then authorized operational traces. Never spend a run rewriting unchanged summaries. Never promote a module to `operationally_validated` from research, a UI label, a connector declaration, a draft, or a passed offline test alone.
