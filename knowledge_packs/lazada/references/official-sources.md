# Lazada official evidence anchors

Checked: 2026-07-18 through 2026-07-19 (Asia/Shanghai)

Use this file as a dated evidence index, not as proof of a live store connection. Recheck volatile rules before any external action.

## Authorization and six-country identity

- [Seller authorization introduction](https://open.lazada.com/apps/doc/doc?docId=108260&nodeId=10777) — last updated 2026-03-05. Lazada documents OAuth2 code-for-token authorization for SG/MY/TH/VN/ID/PH. Local stores and single-site cross-border stores select one site; cross-border sellers may select Crossborder. The token response contains `country_user_info` with a country, seller ID and short code for each authorized store. A shared cross-border token therefore does not erase country-store identity.
- The same current page distinguishes ABA (binding-user/whitelist), ALA (login-user) and ASA (subscriber) authorization. It states that local subscriptions and cross-border authorization have different prerequisites, and documents token/refresh expiry fields. Treat all policy and lifetime values as volatile and read them from the actual app/response rather than hard-coding examples.
- [Choice Seller Authorization Process](https://open.lazada.com/apps/doc/doc?docId=121782&nodeId=45695) — last updated 2025-09-03. Choice uses a separate authorization flow across the same six country IDs. This does not establish Choice as an executable `official_full_managed` store model for T One.
- [Lazada Open Platform developer agreement](https://open.lazada.com/apps/doc/doc?docId=120731&nodeId=30412) — last updated 2024-07-18. The agreement identifies the six Lazada country domains and supplies the legal/API usage boundary.

Browser evidence on 2026-07-18: the public authorization page was opened and inspected. Clicking the visible `AI Assistant` entry redirected to Open Platform login; no credentials were entered, so the assistant's real inputs, outputs, editing/submission boundary and metrics remain blocked.

## Listing, category and multi-site products

- [Product API](https://open.lazada.com/apps/doc/doc?docId=108146&nodeId=10556) — last updated 2024-07-18. Documents product creation, update, price/quantity and QC-related capabilities. API availability is not proof that the current app or seller granted the required category.

- [CreateGlobalProduct payload](https://open.lazada.com/apps/doc/doc?docId=121751&nodeId=30715) — last updated 2024-08-12. This is a multi-site product operation, not one regional store.
