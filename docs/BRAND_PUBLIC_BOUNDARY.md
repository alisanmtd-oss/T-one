# T One Public Brand Boundary

## Included in the public staging package

- Product name: `T One`.
- Public repository name: `T-one`.
- Text wordmark: `T One`.
- Interface direction: local-first, evidence-led, calm and operational rather than promotional.
- Core palette: ink `#17191c`, muted `#6b7179`, teal `#0f766e`, soft teal `#edf8f6`, canvas `#f7f8f9`, white `#ffffff`.
- Interaction principle: real status, explicit authorization, and visible execution boundaries.

## Excluded until ownership or redistribution rights are confirmed

- Raster or vector logos not created specifically for the public package.
- Customer, supplier, marketplace, platform, or partner marks.
- Product photography, listing images, screenshots, videos, and recovered conversation assets.
- Private campaign names, store names, seller identities, contact information, and operating evidence.

The public staging package therefore uses a text-only T One identity. Adding a logo or third-party mark requires a separate rights review.
